# Telegram Profile Music Downloader

Инструмент на Python для работы с аудиофайлами в Telegram через пользовательский аккаунт. Авторизация выполняется с помощью QR-кода.

## Возможности

- 🔐 Авторизация в Telegram по QR-коду
- 🎵 Поиск аудиофайлов в доступной истории чатов
- 📥 Скачивание аудиофайлов на устройство
- 📱 Работа в Termux на Android
- 🐍 Python и Telethon

> Примечание: проект скачивает аудиофайлы из доступной истории сообщений. Он не гарантирует скачивание музыки из специального раздела музыки профиля Telegram.

## Требования

- Android с установленным Termux или Linux
- Python 3
- Аккаунт Telegram
- API ID и API Hash Telegram

Получить API ID и API Hash можно на официальном сайте:
https://my.telegram.org/

## Установка в Termux

Обнови пакеты:

```bash
pkg update && pkg upgrade
```

Установи Python и Git:

```bash
pkg install python git
```

Склонируй репозиторий:

```bash
git clone https://github.com/suyziss/telegram-profile-music.git
cd telegram-profile-music
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

## Авторизация

Запусти скрипт авторизации:

```bash
python auth.py
```

Введи API ID и API Hash, когда программа запросит их.

Затем открой Telegram:

1. Перейди в Настройки.
2. Открой раздел «Устройства».
3. Выбери «Подключить устройство».
4. Отсканируй QR-код, показанный в Termux.
5. Если включена двухэтапная аутентификация, следуй подсказкам программы.

Не передавай файл сессии другим людям.

## Запуск загрузчика

После успешной авторизации запусти:

```bash
python downloader.py
```

Следуй инструкциям в терминале и укажи профиль или пользователя, если программа запросит его.

## Где находятся скачанные файлы?

Путь зависит от настроек загрузчика. В Termux файлы могут сохраняться в папку `Music` или в общую папку музыки Android.

Если используешь общую память Android, сначала предоставь Termux доступ:

```bash
termux-setup-storage
```

## FAQ

### QR-код истёк. Что делать?

Запусти авторизацию повторно:

```bash
python auth.py
```

Используй актуальный QR-код. Если ошибка повторяется, проверь интернет-соединение и версию Telethon.

### Программа не находит музыку

Загрузчик работает с аудиофайлами в доступной истории сообщений. Убедись, что выбран правильный пользователь или чат и что в его истории есть аудио.

### Появилась ошибка `ModuleNotFoundError`

Установи зависимости ещё раз:

```bash
pip install -r requirements.txt
```

### Появилась ошибка авторизации?

Проверь API ID и API Hash. Не публикуй их в открытом доступе. Если сессия недействительна, выполни авторизацию заново.

### Можно ли публиковать файл сессии?

Нет. Файл сессии может предоставить доступ к аккаунту Telegram. Не добавляй его в GitHub, не отправляй другим людям и не включай в архив проекта.

### Как обновить проект?

```bash
git pull
pip install -r requirements.txt
```

Перед обновлением сохрани собственные изменения.

## Безопасность

- Никогда не публикуй API Hash, токены, пароли или файлы сессии.
- Не загружай личные аудиофайлы в публичный репозиторий.
- Используй инструмент только с аккаунтом и материалами, к которым у тебя есть законный доступ.
